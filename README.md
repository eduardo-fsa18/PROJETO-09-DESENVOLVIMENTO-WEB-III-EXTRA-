Sistema de Reserva de Quartos

Sistema para gerenciamento e reserva de quartos de hotel, desenvolvido para a disciplina de Desenvolvimento Web III (FATEC).

🚀 Como Executar

Instale as dependências:

npm install


Inicie o servidor:

npm start
# ou
node server.js


Acesse no navegador:
http://localhost:3000

📁 Estrutura do Projeto

server.js — Servidor Express (API e rotas)

data/ — Arquivos JSON para persistência dos dados (rooms.json, reservations.json)

public/ — Interface web (HTML, CSS e JavaScript)

🛠️ Tecnologias Utilizadas

Node.js

Express

HTML5 / CSS3 / JavaScript
